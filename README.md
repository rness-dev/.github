# rness-dev/.github

Organisation-wide defaults for [rness-dev](https://github.com/rness-dev).

GitHub reads this repository in two ways:

- `profile/README.md` is the public organisation profile shown on
  [github.com/rness-dev](https://github.com/rness-dev).
- The community health files below apply to every repository of the
  organisation that does not ship its own file of the same kind. A file in a
  repository always wins over the default here.

| File | Purpose |
| --- | --- |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability, supported versions, scope |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to propose a change, local setup, checks, commit and release conventions |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Contributor Covenant 2.1 and how to report a conduct issue |
| [`SUPPORT.md`](SUPPORT.md) | Where to ask a question or report a bug |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Bug report and feature request forms, security contact link |
| [`.github/pull_request_template.md`](.github/pull_request_template.md) | Pull request checklist |

## Editing

Keep these files short and true for every repository they apply to. A rule
that concerns one repository belongs in that repository (its `README.md`, or
its own `CONTRIBUTING.md` when it needs one), not here.
